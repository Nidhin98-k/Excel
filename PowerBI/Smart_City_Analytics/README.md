# Smart City Analytics Dashboard

An interactive Power BI dashboard designed to analyze urban mobility, traffic conditions, and smart city operations through interactive visualizations and KPIs.

## Project Overview

This project transforms city and traffic data into an interactive analytics solution that helps users explore traffic patterns, city-level performance, and mobility indicators.

The dashboard is designed with a modern dark-theme interface and interactive navigation to make complex city data easier to understand.

## Key Features

- Executive-level KPI overview
- City-level analysis
- Traffic performance analysis
- Traffic Index and Live Traffic Index
- Traffic intensity analysis
- Interactive city map
- Vehicle and mobility analysis
- Dynamic slicers and filtering
- Interactive page navigation
- Drill-down and detailed analysis
- Google Maps integration for selected cities
- Modern dark-theme dashboard design

## Dashboard Pages

### 1. Executive Overview
Provides a high-level summary of smart city and mobility performance using key KPIs and visualizations.

### 2. Traffic Analysis
Focuses on traffic conditions, traffic index, traffic intensity, and mobility-related trends.

### 3. City Details
Provides detailed city-level analysis with interactive map-based exploration and supporting metrics.
